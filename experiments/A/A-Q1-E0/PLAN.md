## 1. 目标、唯一变化与执行前提

### 1.1 实验目标与可证伪问题
在 `A-Q1-M0` 已批复数学规范下，**仅采用经典基线链路（`M0-Cal-Base` → `M0-DW-Base` → `M0-Rng-Base`）**，按“合成闭环 → 校准实测先导 → 冻结配置 → 单次留出盲评”的严格顺序，验证：
1. 63 路实测阵列的空场校准能否在带内有效压低通道幅相差异；
2. 射频镜像对齐减除能否抑制直射波，同时在近距离目标（`42 cm` 墙体）与金属板（`69 cm`）上保留目标回波；
3. 归一化匹配统计量（`P_norm`、`P_norm,eff`、`P_env`）在有限先导样本上的测距误差与峰旁瓣比表现。

### 1.2 边界与唯一变化声明
- **严格不引入 `N0` 改进**：本试验**不包含** `M0-Cal-Joint`、`M0-DW-Subspace`、`M0-Rng-WLS`、非等权信道加权、深度学习或大范围超参搜索。
- **执行前置门控（缺一不可）**：
  1. `D0` 读取器（PR #7）验收合并至 `main`；
  2. `D1` 折迭与一致性门控小分支完成并验收（交付 `signals_folded (64, 4000)` 与逐包相位漂移/拒绝日志）；
  3. 统筹 `codex` 正式记录 `A-Q1-E0` 批复。

## 3. 固定经典基线配置（对应 `config.json`）

所有物理常量与经典基线公式严格遵循 `solutions/A/model_q1.md`（`098e17d`）：
- **物理常量**：$c_0 = 299792458\text{ m/s}$，$f_s = 4\text{ GHz}$，$N_p = 4000$，$\mathcal{B} = [0.3, 1.7]\text{ GHz}$，$\mathcal{B}_{\text{core}} = [0.4, 1.6]\text{ GHz}$，$\text{tx\_idx}=27$，$\text{ref\_idx}=28$（63 路有效接收）。
- **1.1 通道校准（`M0-Cal-Base`）**：
  - 使用 10 组空场数据（以 `空场数据/data1` 为时间原点对齐聚合 $\bar{X}^{\text{air}}$）。
  - Tikhonov 正则化系数默认固定 $\lambda_{\text{cal}} = 10^{-3}$、$\lambda_{\text{inv}} = 10^{-3}$；若空场留一交叉验证显示边界过拟合或噪声放大，**仅允许**在校准集上从离散网格 $\{10^{-4}, 10^{-3}, 10^{-2}\}$ 择优并立即冻结。
- **1.2 直射波抑制（`M0-DW-Base`）**：
  - 带内逆校准后，按第二奈奎斯特区射频移位 $e^{+j 2\pi f_R \Delta t_0}$ 对齐空场模板（粗搜包络峰 $\pm 1\,T_s$ 内以 $10^{-3}\,T_s$ 步长精搜）。
  - 主基线固定模板系数 $\alpha_g \equiv 1.0$；并行记录单实标量 $\hat{\alpha}_g$ 拟合值作对照诊断。
- **1.3 测距（`M0-Rng-Base`）**：
  - 统一等权 $w_i \equiv 1.0$（63 路，若 D1 标记个别无效通道则剔除并记录）。
  - 搜索范围 $d \in [0.15, 2.00]\text{ m}$（粗搜 $1\text{ mm}$，峰值邻域精搜 $0.1\text{ mm}$）。
  - 主基线报告 `P_norm`，同步横向对比 `P_norm,eff`（显式 $\hat{S}_{\text{eff}}$ 色散模板）与 `P_env`（非相干包络）；墙体首峰判别规则必须在校准样例阶段确定并冻结，不得看留出样后修改。

## 4. 严格三阶段执行顺序与样本清单

### 阶段 1：合成例闭环（`Phase E0-S`，不读取真实 `.dat`）
1. **`E0-S1`（2 路解析闭环，复用 M0 §8）**：
   - 参数：$d_{\text{true}} = 0.600000\text{ m}$，$\Delta\tau_2 = 0.50\text{ ns}$，$G_2 = 1.25$，$\psi_2 = 0.30\text{ rad}$，$\tau_{\text{ref}}^{\text{hw}} = 0.20\text{ ns}$。
   - **预期**：`P_norm` 与 `P_norm,eff` 均收敛至 `0.600000 m`，校准参数误差 $\le 10^{-6}$ 量级。
2. **`E0-S2`（63 路全阵列合成闭环，含加性高斯白噪声）**：
   - 参数：按真实 64 路阵列坐标（屏蔽 `tx_idx=27`）生成 63 路合成空场与目标回波，植入随机硬件偏差（固定随机种子 `seed = 20261128`）、非整数异步偏移 $t_0^{(g)}$ 与高斯白噪声（`SNR = 25 dB`），测试 $d_{\text{true}} \in \{0.42, 0.69\}\text{ m}$。
   - **预期**：全链路 63 路自动恢复测距误差 $\le 1.0\text{ cm}$，直射波抑制比 $\ge 20\text{ dB}$。

### 阶段 2：校准实测先导与配置冻结（`Phase E0-C` → `E0-Freeze`）
1. **输入范围（严格限定）**：
   - 空场模板与自检：`空场数据/data1`–`data10`（10 组，先对已侦察 `data1`–`data5` 核对 D1 折迭，再并入 `data6`–`data10` 并运行空场留一交叉抑制比测试）。
   - 目标校准先导样例（仅取前期已披露的 2 组，不扩至检验集）：
     - `墙体数据/data1-42cm`（`wall_cal`，真值 `42 cm`，用于检查近距离墙体目标回波保留率与前峰判定）；
     - `金属板数据/data1-69cm`（`metal_cal`，真值 `69 cm`，用于检查金属板强反射测距）。
2. **配置冻结闸门（`E0-Freeze`）**：
   - 仅当 `E0-S` 与 `E0-C` 均通过第 5 节门控后，锁定最终 $\lambda_{\text{cal}}, \lambda_{\text{inv}}, \alpha_g$ 模式、主测距统计量（如验证是否存在显著公共色散决定主报 `P_norm` 还是 `P_norm,eff`）及墙体首峰门限，生成冻结版 `config.frozen.json` 并提交记录 SHA。
   - **冻结后严禁再改动任何参数、阈值或估计器逻辑**。

### 阶段 3：单次留出样例盲评（`Phase E0-T`，冻结后仅运行一次）
1. **输入范围（仅 1+1 组内插留出样，不查看其余 8+8 组）**：
   - `墙体数据/data20-73cm`（`wall_test`，真值 `73 cm`，位于校准距离 `42–106 cm` 内部，避免提前触及 `121 cm` 外推端）；
   - `金属板数据/data5-60cm`（`metal_test`，真值 `60 cm`，位于校准距离 `48–91 cm` 内部，避免提前触及 `99 cm` 外推端）。
2. **输出要求**：同时对比 `P_norm`、`P_norm,eff`、`P_env` 的测距结果及全部伴随诊断指标（见第 5 节），如实汇报，不论成败均保留原始日志与退出状态。

## 5. 评价指标、门控阈值与依据

为避免“只挑有利指标”或“无依据捏造阈值”，所有指标必须成套输出，阈值依据分为**物理分辨率推导**与**先导工程门限**两类：

| 阶段 / 维度 | 指标 | 门控 / 停止阈值 | 依据说明 |
|---|---|---|---|
| **D1 前置** | 有效接收通道数、NaN/Inf 检查、包间相位滑移 | `valid_rx == 63`（无 NaN/Inf）；异常漂移须记日志 | M0 §1.1 / §1.2；已观测 `空场 data2` 行 2 存在跨包滑移 |
| **合成闭环 (`E0-S1`)** | 测距绝对误差 / 时延还原误差 | `abs_err <= 0.05 cm` / `<= 0.001 ns` | $0.1\text{ mm}$ 细搜网格与无噪闭环数值精度上限 |
| **合成加噪 (`E0-S2`)** | 测距绝对误差 / 直射波抑制比 | `abs_err <= 1.0 cm` / `DW_supp >= 20 dB` | $< 0.1\times$ 瑞利距离分辨率 $\Delta R = c_0/(2B) \approx 10.71\text{ cm}$ |
| **空场留一交叉** | 模板对齐后残余功率抑制比（dB） | 预期 $\ge 10\text{ dB}$；**`< 6 dB` 硬停止** | 先导工程门限：`6 dB` 对应残余幅值仍达原直达波 $50\%$，说明对齐/行板同步失配 |
| **校准前 (`1.1`)** | 带内通道间幅相残差降幅（dB） | 须记录校准前后对比（不预设硬淘汰线，供诊断） | 评估端射互耦 $E_i^{\text{dir}}$ 与设备离散度 |
| **抑制后 (`1.2`)** | 直射波窗残余降幅（dB）& 近距回波 PSLR | `42 cm` 样例目标峰高于直达波残余且 `PSLR >= 3.0 dB` | 防止抑制步吞掉近距（$\Delta\tau \approx 2.6\text{ ns}$）真实回波 |
| **校准测距 (`1.3`)** | `abs_err_cm`（`P_norm` / `P_norm,eff` / `P_env`） | 先导通过 `<= 5.0 cm`；**`> 10.71 cm` 硬停止** | $5.0\text{ cm} \approx 1.33$ 个采样步（$3.75\text{ cm}$）；$10.71\text{ cm}$ 为 1 个瑞利主瓣宽度，超限即主峰误锁 |
| **留出盲评 (`E0-T`)** | `abs_err_cm`, `rel_err_pct`, `PSLR_db`, 抑制比 | **只做真实记录与验收评价，不设反调门槛** | `coordination/A_Q1_METHODS.md`：检验标签不得反向调参 |

## 6. 资源预算、硬停止条件与失败回溯

### 6.1 计算预算（按 `coordination/A_Q1_METHODS.md` 规定）
- **硬件与线程**：单进程 CPU，强制设置 `OMP_NUM_THREADS=1`、`OPENBLAS_NUM_THREADS=1`、`MKL_NUM_THREADS=1`、`NUMEXPR_NUM_THREADS=1`。
- **时间与内存上限**：总墙钟时间 `<= 600 s`（10 分钟），峰值常驻内存（RSS）`<= 4096 MiB`（4 GiB）。

### 6.2 立即停止条件（任一触发即中止本次实验）
1. 运行时长超 `600 s` 或峰值内存超 `4096 MiB`；
2. 出现 `NaN`、`Inf`、文件读取失败或输入校验哈希不匹配；
3. `E0-S1` / `E0-S2` 任一项未通过；
4. 空场留一交叉抑制比 `< 6.0 dB`；
5. 校准样例出现目标回波被直射波抑制吞没（目标峰未超过噪声门限或 `PSLR < 3.0 dB`）或测距误差 `> 10.71 cm`；
6. 发生任何读取未授权 `wall_test` / `metal_test` 组或用检验标签参与选参的越界行为。

### 6.3 失败登记与回溯协议
- 一旦失败，**禁止自动触发全量重跑或扩大参数搜索**；
- 在 `experiments/A/A-Q1-E0/` 留存：实际运行命令、冻结/使用配置、随机种子、环境版本、运行时间、峰值内存、失败退出原因及阶段影响范围；
- 回到最近通过验收的提交（`b40e15b` 或执行前已验收的 D0/D1 提交），由统筹组织建模、数据、验证三方诊断（例如排查空场端射耦合偏置或跨行板时间抖动 $\delta t_{g,r}$），形成新的小修方案后另行报批。
