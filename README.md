# Mathmodal 数学建模协作仓库

本仓库保存竞赛原题、原始附件和四个 Agent 的协作约定。新加入的 Agent 先读 [工作流](AGENTS.md)，再按 [团队分工](团队分工.md) 打开自己的角色文件。

| 目录 | 用途 |
| --- | --- |
| [竞赛题目](竞赛题目/) | A、B 两道题的原文和附件，保留原始文件名与相对位置 |
| [roles](roles/) | 四个 Agent 各自的职责、交付对象与验收要求 |

选题后按需建立 `solutions/<题号>/` 保存模型、数据处理和求解代码，`checks/<题号>/` 保存独立验证，`paper/<题号>/` 保存论文和制图脚本。运行生成的临时文件放在本机，只提交复现所需的代码、参数、关键结果和对应说明。
