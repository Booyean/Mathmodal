# A-Q1-E0-S1/S2 预登记接口裁定（2026-11-28）

状态：统筹裁定，适用于 `checks/A/e0_s1s2_prereg.md`（E0-PREREG-1，提交 `b3fabbb779b93c142df4a81a6bc967be27f0741f`）之后的首个 E0-S 实现。此裁定先于实现 SHA 固定；不修改已批复的 `experiments/A/A-Q1-E0/PLAN.md`、`config.json` 或冻结拆分。

## 1. 门控适用范围

- `E0-S1` 是明确的 2 路无噪例外，只检验方案与预登记中的测距、相对时延及有效零点；63 路门控和 S2 回波质量门控不适用。
- `E0-S2@0.42` 和 `E0-S2@0.69` **各自**必须满足 `abs_err <= 1.0 cm`、`Supp_dw-win >= 20 dB`、`PSLR >= 3 dB`、`PNR >= 6 dB`，有效 RX 为 63 且结果全有限。近距回波质量门同时适用于 S2 和后续 E0-C，不得以“仅 C 阶段适用”为由豁免 S2。
- `PNR` 的分母是已批准的压缩延迟域 `W_bg=[50,950] ns` 背景**代理**，不是已证明的纯热噪声；`PSLR` 使用 `P_norm,eff` 的已批准搜索区与主瓣保护带。两指标均从实现输出数组独立重算。
- 任何 S2 门失败即按预登记记录失败并停止，不自动改种子、参数、阈值或扩样。

## 2. 固定随机数调用顺序

只用一条 `numpy.random.default_rng(20261128)` 流。首先按 `rx_idx` 升序（排除 `tx_idx=27` 与 `ref_idx=28`）每通道连续抽 `delta_tau_s`、`gain_mag`、`psi0_rad`、`psi2_u2_rad`；所得 62 行表必须与 `checks/A/e0_s2_param_table.json` 的规范 SHA256 `aa86bf56fb138789cd0ad4375691293e7d0e5d65a2daf678d151d44720576e96` 一致。

随后顺序抽取 11 个 `Uniform(0,T_p)` 触发偏移：依次赋予 `air_1` 至 `air_9`，再赋予目标 `0.42 m`、`0.69 m`；`air_0=120.25 T_s` 固定，不消耗随机数。之后按 `air_0` 至 `air_9`、目标 `0.42 m`、目标 `0.69 m` 的顺序为每组调用**一次** `rng.standard_normal((63,4000))`；矩阵行按有效 RX 升序（含参考 28），列按样点 `m=0..3999`。将各组标准正态矩阵乘以该组的噪声标准差，叠加于经过硬件频响与传播延迟、已重构为 4000 点实序列的信号。目标组的标准差按该目标的 63 路纯回波平均时域功率及 25 dB SNR 计算；空场没有目标回波，统一采用 `0.42 m` 纯目标回波的同一功率基准。记录 numpy 版本；逐位复现要求在**同一运行环境**内成立。

生成器、被验估计器均不得读取真实 `.dat`；真值 `d_true` 只用于合成植入与最终误差计算，不得作为估计器输入或选峰依据。实现导出完整参数表及触发偏移、噪声矩阵的 SHA256，供独立验证重建。

## 3. 最低结果接口

提供一条可复跑 CLI 命令和机器可读 JSON，至少包含 `experiment_id`、`phase`、实现完整 SHA、父提交、配置 SHA256、Python/numpy 版本、墙钟秒数、峰值 RSS MiB，以及逐例 `E0-S1`、`E0-S2@0.42`、`E0-S2@0.69`。每例分别给出 `d_true_m`、`d_hat_m`、`abs_err_cm`、适用的门控指标、`valid_rx`、`finite`、种子、停止/失败原因和所交数组的 SHA256。S1 的不适用指标填 `null` 并注明原因，不填伪零。输出用于重算的逐通道压缩响应、减除前后频谱或等价无损数组及采样轴、网格、单位；文件名和内部键可自定，但必须在同一提交的接口说明中给出映射。

`implementation_sha` 应对应结果所用代码提交；实现先提交、再从该提交运行并登记结果，避免自引用 SHA。`verify_e0_spec.py` 使用真值模板与精确空场，只是度量反例，不得替代 E0-S 求解器。E0-S 验收通过前，E0-C 真实校准及 E0-T 留出仍不放行。
