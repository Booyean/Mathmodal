## 1. 一句话提案

在**不改变**已冻结经典基线（`M0-Cal-Base` + `M0-DW-Base`，`α≡1`）的前提下，只做**一项**
改动：把“单秩均值模板减除”换成**秩 2 空场子空间 + 仅在直射波主窗内拟合 2 个复系数**，
用同一批 12 组白名单数据、同一套门槛，检验空场 LOO 抑制能否从 **2.98 dB** 抬到 **≥10 dB**。

## 2. 为什么是这一项（而不是换 λ / 换模板 / 重跑）

诊断已排除的路径（详见诊断 §3、§6）：

| 路径 | 实测结论 |
|---|---|
| 重选 λ（9 对固定网格） | `data1`/`data2` 的上端只有 4.43 / 3.13 dB；两折对 λ 最不敏感（0.34 / 0.22 dB）→ 换 λ 不可能过线 |
| 换模板估计器（中位/几何中位/鲁棒权重） | 留出折是少数簇，其相对多数簇的偏差即残差本身；换估计器不增加表示能力 |
| 重跑同一配置 | 数值可复现（C10 偏差 3.6e-15 dB），重跑只会得到同一失败 |
| 调阈值 | 属于“看到失败后改门槛”，禁止 |

唯一可能有效的单因子方向是**增加模板的表示能力**：10 组空场里存在 5 个采集簇（偏移分簇，
簇内残余形状相关 0.97–0.99），单秩模板只能表示“所有簇的公共分量”，无法表示簇间差异；
秩 2 至少能容纳“公共分量 + 一个簇间差异模态”。这正是 `model_q1.md` 已登记的改进候选，
不是新方法。

## 3. 方法定义（单因子，无搜索）

记带内逐频点、逐通道对齐并逆校正后的空场谱为 `X_g(f) ∈ C^63`（`g = 1..10`，`f ∈ B`），
留出折 `h` 时：

1. **模板池**：`P = {X_g : g ≠ h}`（基线与 N0 完全相同，不用任何目标标签）。
2. **秩 2 基**：`T(f) = mean_{g∈P} X_g(f)`；
   `D_1(f)` = 中心化偏差矩阵 `[X_g(f) − T(f)]_{g∈P}` 的第一左奇异向量（逐频点）。
   基 `B(f) = [T(f), D_1(f)] ∈ C^{63×2}`。
3. **窗内拟合**：在压缩域 `z_i(τ)` 上，只取直射波主窗
   `|wrap(τ − τ_i^dir)| ≤ 1.0 ns` 内的样本，按最小二乘拟合复系数
   `(a, b) = argmin Σ_{i,τ∈W} | z_i^X(τ) − a·z_i^T(τ) − b·z_i^{D_1}(τ) |²`。
4. **抑制输出**：`X̃ = X_h − a·T − b·D_1`。

**对照（同一套代码，只改一个量）**：

| 臂 | 基 | 系数 | 说明 |
|---|---|---|---|
| `C0` 基线 | `[T]` | `a ≡ 1`，无拟合 | 已登记 `b63e217`，不重跑 |
| `C1` 单秩拟合 | `[T]` | 窗内拟合 `a` | 隔离“拟合系数”的贡献 |
| `C2` 秩 2（**本提案**） | `[T, D_1]` | 窗内拟合 `a, b` | 隔离“第二模态”的贡献 |

- 秩固定 `r=2`，**不做秩网格搜索**；`D_1` 的符号用“与 `T` 内积为实”规范化，保证确定性。
- 直射波窗沿用 `E0-PREREG-3` §5 的定义（`±1.0 ns`，`wrap` 到 `T_p`），不新增窗参数。
- λ 固定为 `(1e-3, 1e-3)`（`b63e217` 的选中对），**不重选**；`η_wall` 固定 `0.25`。

## 5. 通过指标（预登记；全部满足才算 PASS）

| 编号 | 指标 | 门槛 | 作用 |
|---|---|---|---|
| **P1** | **跨采集簇留出**（5 折，每折留出同簇 2 组，基由其余 8 组构造）的 `min(Supp)` | **≥ 10.0 dB** | 本提案的**主判据**：唯一不能被“同簇伙伴仍在模板里”解释的度量 |
| P2 | 已登记的 10 折 LOO `min(Supp)` / `median(Supp)` | **≥ 10.0 / ≥ 10.0 dB** | 与 `b63e217` 直接可比 |
| P3 | 目标侧非退化：墙体 `PSLR` / `abs_err`，金属 `PSLR` / `PNR` | 不劣于基线 `2.6643 dB / 6.18 cm / 4.1726 dB / 35.4293 dB`（各自 ±0.05 dB 与 ±0.05 cm 容差内） | 证明秩 2 没有把目标回波一起减掉 |
| P4 | 合成回波保留（`E0-S` 夹具，42 cm 目标注入） | 目标峰损失 **≤ 0.1 dB**，测距偏移 **≤ 2 mm** | 直射波窗拟合的“零目标泄漏”守卫 |
| P5 | 验收器 C1–C15（`E0-PREREG-3` + 两进程 C12） | 全 PASS | 接口/复算/边界不退化 |

- **P1/P2 的窗口口径**：`Supp` 仍按 `10·log10(Σ p_cal / Σ p_sup)` 由交付数组重算，验收方
  无需导入生产代码。
- **P1 是度量新增项**，需要统筹与验证方同意后才能写进预登记；理由见诊断 §5（现有 10 折
  LOO 的留出组总带着同簇伙伴，度量的实际语义是“同批次可复现性”）。若统筹**不批准** P1，
  则本提案降级为“只报 P2”，并须在结论里注明该限制。

## 6. 停止条件（任一触发即停，不自动重跑/扩样/搜索）

| 编号 | 条件 | 处置 |
|---|---|---|
| S1 | P1（或降级后的 P2）仍 `< 6.0 dB` | 停在硬停；**不得**加秩到 3、不得重选 λ、不得改阈值；结论记“空场池不张成批次差异” |
| S2 | P1 过线但 P3 任一项退化超容差 | 停；记“抑制收益以目标回波为代价”，回退基线 |
| S3 | P4 合成保留守卫失败 | 停；该方法不得进入实测评价 |
| S4 | 边界变化（`opened_files≠96`、`valid_rx<63`、锚点/`inputs` SHA 不符、路径校验拒绝） | 停；按 S4 退回数据方 |
| S5 | 资源超预算（单次 >600 s 或 >4096 MiB；两次顺序合计 >600 s） | 停；不缩样、不改分块参数重跑 |
| S6 | 任何“再试一个秩/窗宽/λ/η”的想法 | 属于新一轮预登记，本轮直接结束 |
| S7 | P1/P3/P4 全过但墙体 `PSLR < 3.0 dB` 或 `abs_err > 5.0 cm` | **不算 N0 失败**：记“抑制已改进、测距门槛仍被另一机制挡住”，交统筹决定是否另立测距单项（`M0-Cal-Joint` 或 `M0-Rng-WLS`），不在本轮混入 |

**不失败即通过的部分**：S7 情形下本轮仍产出可引用的“抑制改进已达成、整轮仍不可冻结”的结论，
但不写 `e0c_frozen.json`、不放行 `E0-T`。

## 7. 可证伪预测

| 预测 | 若成立 | 若不成立 |
|---|---|---|
| 秩 2 能把 10 折 LOO 的 `data1`/`data2` 各抬 ≥5 dB | 说明第二模态确实承载了簇间差异 → 继续 P1 | 第二模态没抓到该差异 → 按 S1 停，转行板抖动诊断 |
| 跨簇留出（P1）也能抬 ≥3 dB（相对基线同折） | 说明收益可跨批次迁移 → N0 结论成立 | 收益只来自“同簇伙伴在模板里” → 明确记录为**不可迁移**，不得写成方法有效 |
| 目标峰损失 ≤0.1 dB | 窗内两系数拟合没有吃掉 42 cm 回波 | 说明窗/拟合口径需重做，按 S3 停 |
