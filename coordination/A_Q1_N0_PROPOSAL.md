## 1. 一句话提案

在**不改变**已冻结经典基线（`M0-Cal-Base` + `M0-DW-Base`，`α≡1`）的前提下，只做**一项**
改动：把“单秩均值模板减除”换成**秩 2 空场子空间 + 仅在直射波主窗内拟合 2 个复系数**，
用同一批 12 组白名单数据、同一套门槛，检验空场 LOO 抑制能否从 **2.98 dB** 抬到
**≥10 dB**（主判据为五折跨采集簇留出 `P1`，见 §5）。

**判定拆成两级**：`L1` 只回答“抑制方法本身是否达标”，`L2` 才回答“整轮是否具备冻结资格”。
`L1 PASS` 不等于可冻结；`C1–C15` 全 PASS 也不等于可冻结（灰区仍须挡住）。

## 2. 为什么是这一项（而不是换 λ / 换模板 / 重跑）

诊断已排除的路径（详见诊断 §3、§6）：

| 路径 | 实测结论 |
|---|---|
| 重选 λ（9 对固定网格） | `data1`/`data2` 的上端只有 4.43 / 3.13 dB；两折对 λ 最不敏感（0.34 / 0.22 dB）→ 换 λ 不可能过线 |
| 换模板估计器（中位/几何中位/鲁棒权重） | 留出折是少数簇，其相对多数簇的偏差即残差本身；换估计器不增加表示能力 |
| 重跑同一配置 | 数值可复现（C10 偏差 3.6e-15 dB），重跑只会得到同一失败 |
| 调阈值 | 属于“看到失败后改门槛”，禁止 |

唯一可能有效的单因子方向是**增加模板的表示能力**：10 组空场里存在 5 个采集簇（偏移分簇，
簇内残余形状相关 0.97–0.99），单秩模板只能表示“所有簇的公共分量”，无法表示簇间差异；
秩 2 至少能容纳“公共分量 + 一个簇间差异模态”。这正是 `model_q1.md` 已登记的改进候选，
不是新方法。

## 3. 方法定义（单因子，无搜索）

记带内逐频点、逐通道对齐并逆校正后的空场谱为 `X_g(f) ∈ C^63`（`g = 1..10`，`f ∈ B`），
留出折 `h` 时：

1. **模板池**：`P = {X_g : g ≠ h}`（基线与 N0 完全相同，不用任何目标标签）。
2. **秩 2 基**：`T(f) = mean_{g∈P} X_g(f)`；
   `D_1(f)` = 中心化偏差矩阵 `[X_g(f) − T(f)]_{g∈P}` 的第一左奇异向量（逐频点）。
   基 `B(f) = [T(f), D_1(f)] ∈ C^{63×2}`。
3. **窗内拟合**：在压缩域 `z_i(τ)` 上，只取直射波主窗
   `|wrap(τ − τ_i^dir)| ≤ 1.0 ns` 内的样本，按最小二乘拟合复系数
   `(a, b) = argmin Σ_{i,τ∈W} | z_i^X(τ) − a·z_i^T(τ) − b·z_i^{D_1}(τ) |²`。
4. **抑制输出**：`X̃ = X_h − a·T − b·D_1`。

**对照（同一套代码，只改一个量）**：

| 臂 | 基 | 系数 | 说明 |
|---|---|---|---|
| `C0` 基线 | `[T]` | `a ≡ 1`，无拟合 | 已登记 `b63e217`，不重跑 |
| `C1` 单秩拟合 | `[T]` | 窗内拟合 `a` | 隔离“拟合系数”的贡献 |
| `C2` 秩 2（**本提案**） | `[T, D_1]` | 窗内拟合 `a, b` | 隔离“第二模态”的贡献 |

- 秩固定 `r=2`，**不做秩网格搜索**；`D_1` 的符号用“与 `T` 内积为实”规范化，保证确定性。
- 直射波窗沿用 `E0-PREREG-3` §5 的定义（`±1.0 ns`，`wrap` 到 `T_p`），不新增窗参数。
- λ 固定为 `(1e-3, 1e-3)`（`b63e217` 的选中对），**不重选**；`η_wall` 固定 `0.25`。

## 5. 两级判定：L1 方法级 / L2 整轮冻结资格

依据：统筹 2026-11-28 复审意见（“抑制方法达标”与“整轮具备冻结资格”分开；五折跨簇最低抑制
`<6 dB` 硬停、`6–<10 dB` 未达标、`≥10 dB` 才满足主指标；灰区即使检查器各项通过也不得冻结）
与 `E0-PREREG-3` §3 的既有门槛（**不新增、不放宽任何门槛**）。

### 5.1 L1 方法级（P1/P2/P3/P4 + P5a）

| 编号 | 指标 | 分层判定 | 作用 |
|---|---|---|---|
| **P1** | **五折跨采集簇留出**的 `min(Supp)`。每折留出**同一采集簇的 2 组**，模板只由其余 **8 组（4 簇）**构造；`P1` = 10 个留出值的最小值 | `<6.0 dB` **硬停**（S1）；`6.0 ≤ P1 < 10.0 dB` **未达标**（S2）；`≥10.0 dB` **满足主指标** | **主判据**：唯一不能被“同簇伙伴仍在模板里”解释的度量 |
| P2 | 已登记的 **10 折 LOO** `min(Supp)` / `median(Supp)` | `min <6.0 dB` 硬停；`6.0 ≤ min < 10.0 dB` 未达标；`min≥10.0` 且 `median≥10.0 dB` 才算满足 | 与 `b63e217` 直接可比；给出同批次下限与整体水平 |
| P3 | 目标侧**非退化**：墙体 `PSLR` / `abs_err`，金属 `PSLR` / `PNR` | **单侧非退化**：`PSLR`/`PNR ≥` 基线 `−0.05 dB`；`abs_err ≤` 基线 `+0.05 cm`（改善不受罚） | 证明秩 2 没有把目标回波一起减掉；**相对判据，不是绝对门** |
| P4 | 合成回波保留（`E0-S` 夹具，42 cm 目标注入） | 目标峰损失 **≤0.1 dB**，测距偏移 **≤2 mm** | 直射波窗拟合的“零目标泄漏”守卫 |
| P5a | 接口与证据链（见 §5.3） | 全 PASS（C9 只取自洽子项，绝对门归 L2） | 保证判定可机械复核、可复算 |

**L1 结论的三种取值（互斥、穷尽）**：

- `L1 = 硬停`：`P1 < 6.0` **或** `P2 min < 6.0`；
- `L1 = 未达标`：`6.0 ≤ P1 < 10.0`（且 `P2 min ≥ 6.0`），或 `6.0 ≤ P2 min < 10.0`；
- `L1 = PASS`：`P1 ≥ 10.0` **且** `P2 min ≥ 10.0` **且** `P2 median ≥ 10.0` **且** `P3`
  **且** `P4` **且** `P5a` 全部满足。

`P1` 与 `P2` 的档位不一致时，按**较低档**定 `L1`（保守），结果表并列两值；只有在同一折/
同一模板的 `Supp` 重算互相矛盾、或两次独立运行指标不一致时，才升级为 §6 `S9` 证据缺陷。

**P3 基线锚点（`b63e217`，单侧下界/上界）**：墙体 `PSLR ≥ 2.6643−0.05 = 2.6143 dB`、
`abs_err ≤ 6.18+0.05 = 6.23 cm`；金属 `PSLR ≥ 4.1726−0.05 = 4.1226 dB`、
`PNR ≥ 35.4293−0.05 = 35.3793 dB`。基线值本身来自 `b63e217` 的标称标签，不是独立真值认证；
P3 只用于“不退化”比较，不构成精度声明。

**P1 折分配冻结**（防止看到 N0 结果后重新分簇）：沿用 `b63e217#cal.shifts_s` 已识别的 5 簇，
按固定配对 `{data1,data2}`、`{data3,data4}`、`{data5,data6}`、`{data7,data8}`、`{data9,data10}`。
N0 **不得**按自己的 `shifts_s` 重新分簇；若 N0 的偏移把某组推到 0.1 ns 容差外，按“边界变化”
（S5）停，交统筹，而不是改折。

**基线 P1 不可复算**：`b63e217` 只交付了 10 折的 `air_loo__p_cal/p_sup`，没有跨簇 5 折的
`p_cal/p_sup`，也没有逐组空场谱；因此**不得**从归档数组推算基线 `P1`，也不得写“相对基线
抬升 N dB”。`P1` 只按**绝对门槛** `≥10 dB` 判；跨版本的比较只用可复算的 `P2`。

**P3 的口径修正（相对 `cfef942`）**：原文“各自 ±0.05 dB 与 ±0.05 cm 容差内”是**双侧带**，
它会把“墙体 `PSLR` 改善到 ≥3.0 dB”误判为退化，并使 `P3` 与 `L2` 在数学上不可同时满足
（基线 `2.6643 + 0.05 = 2.7143 < 3.0`）。本版改为**单侧非退化**：只禁止变差，不禁止改善。
这是本轮修订发现的第二个口径矛盾，请统筹复审确认。

### 5.2 L2 整轮冻结资格

`L2 = PASS` 当且仅当：

1. `L1 = PASS`；
2. `P5a` 全 PASS（含 `E0-C-C12-REPEAT-1` 两进程独立运行证据）；
3. **C9b 绝对目标门**全 PASS：两组目标 `PSLR ≥ 3.0 dB`、`PNR ≥ 6.0 dB`、`abs_err ≤ 5.0 cm`；
4. **无灰区、无硬停**：任一目标 `5.0 < abs_err ≤ 10.71 cm` → `not_eligible_for_freeze`，
   `L2 = FAIL`；`abs_err > 10.71 cm` → 硬停，`L2 = FAIL`；
5. `freeze.status == "eligible"`，且 `e0c_frozen.json` 存在、内容与选定 `(λ_cal,λ_inv,η_wall)`
   及实现 SHA 一致（C11）。

**只有 `L1 = PASS` 且 `L2 = PASS`** 才写 `e0c_frozen.json`，才具备“可放行 `E0-T`”的资格；
是否实际放行 `E0-T` 仍由统筹单独签发（B-02/B-03），本提案不自行放行。

**关键性质：`C1–C15` 全 PASS ≠ 可冻结。** `E0-PREREG-3` 的灰区允许 `C9` 在
`5.0 < abs_err ≤ 10.71 cm` 时 PASS，同时 `freeze.status = not_eligible_for_freeze`。
因此 `L2` 必须显式排除灰区（第 4 条），不能只看检查器总判定。

### 5.3 P5a：接口与证据链（把 C9 拆成 C9a/C9b）

N0 不能直接套用 `accept_e0c.py` 的 C5（C5 明确禁止子空间/N0 混入），需由验证方按同一语义
落 N0 自己的预登记与检查器。为保证口径可比，`P5a` 固定为：

| 子项 | 内容 | 通过标准 |
|---|---|---|
| P5a-1 | 边界/身份/数据/前置/接口：C1–C4、C6–C8、C10、C12–C15 | 全 PASS |
| P5a-2 | **C9a 自洽子项**：`d_hat`/`abs_err` 重算一致；`gate_results` 与独立判定一致；`status` 与硬停/灰区/eligible 分类一致；空场组 `null` 字段不得填伪零 | 全 PASS |
| P5a-3 | **C11 冻结完整性**：未在不可冻结时写 `frozen`；若 `L2` 未成立，`e0c_frozen.json` 必须不存在；`η_wall`/λ/实现 SHA 与选定值一致 | 全 PASS |
| C5' | N0 方法范围：允许“秩 2 子空间 + 窗内两复系数”；禁止秩搜索、λ 重选、自适应 α、WLS/非等权；其余白名单不变 | 声明的 `n0_rank=2`、`n0_arms={c0,c1,c2}`、`n0_grid_search=false` 与实际一致 |

`C9b`（绝对目标门）**只进 L2**，不进 P5a；这样 `P3` 的相对非退化与 `C9b` 的绝对门不再
互相矛盾。

### 5.4 结论矩阵（允许写什么 / 禁止写什么）

| 情形 | L1 | L2 | 允许写法 | 禁止 |
|---|---|---|---|---|
| `P1 < 6.0`（或 `P2 min < 6.0`） | 硬停 | — | “空场池在现有 12 组上不张成批次差异；N0 硬停” | 加秩/重选 λ/改阈值/重跑 |
| `6.0 ≤ P1 < 10.0`（或 `6.0 ≤ P2 min < 10.0`） | 未达标 | — | “抑制有部分改善，但未达 10 dB 主指标” | 写“方法有效/通过”，写 frozen |
| `L1 PASS` 且 `L2 FAIL` | PASS | FAIL | “抑制方法达标；整轮因 `C9b`/灰区不可冻结（逐项列原因）” | 写 frozen、放行 E0-T、把 `d_hat` 当结果 |
| `L1 PASS` 且 `L2 PASS` | PASS | PASS | 写 `e0c_frozen.json`；交统筹签发 E0-T | 自行放行 E0-T、跳过统筹 |

## 6. 停止条件（任一触发即停，不自动重跑/扩样/搜索）

| S6 | 资源超预算（单次 `>600 s` 或 `>4096 MiB`；两次顺序合计 `>600 s`） | 停；不缩样、不改分块参数重跑 |
| S7 | 任何“再试一个秩/窗宽/λ/η”的想法 | 属于新一轮预登记，本轮直接结束 |
| S8 | `L1 PASS` 但 `L2 FAIL`：墙体 `PSLR < 3.0 dB`、`PNR < 6.0 dB`、`abs_err > 5.0 cm`（含 `5.0 < abs_err ≤ 10.71` 灰区），或 `freeze.status ≠ eligible` | **不算 N0 失败**：记“抑制方法达标、整轮仍不可冻结（逐项原因）”；不写 frozen、不放行 `E0-T`；交统筹决定是否另立测距单项（`M0-Cal-Joint` / `M0-Rng-WLS`），不在本轮混入 |
| S9 | 证据缺陷：同一折/同一模板的 `Supp` 重算不一致；两次独立运行指标不一致；C 检查互相冲突；从归档数组推算基线 `P1`，或把 `P2` 的 10 折值当作 `P1` | 停；按**证据缺陷**报告，不重跑、不改判，直到缺陷定性 |

**“不失败即通过”的部分**：S8 情形下本轮仍可产出可引用的 **`L1 PASS / L2 FAIL`** 结论，
但不写 `e0c_frozen.json`、不放行 `E0-T`；硬停运行里的 `d_hat` 一律不得当结果引用。

## 7. 可证伪预测

| 预测 | 若成立 | 若不成立 |
|---|---|---|
| 秩 2 能把 10 折 LOO 的 `data1`/`data2` 各抬 ≥5 dB | 说明第二模态确实承载了簇间差异 → 继续看 P1 | 第二模态没抓到该差异 → 按 `P2 min` 落 S1（<6）或 S2（6–<10） |

| 目标峰损失 ≤0.1 dB | 窗内两系数拟合没有吃掉 42 cm 回波 | 说明窗/拟合口径需重做，按 S4 停 |
