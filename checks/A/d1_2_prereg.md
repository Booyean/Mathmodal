## 1. D1-1 已知缺陷（本轮必须被修复的两项）

**F1（中）锚包选择只用 `rho` 中位数。** 极性翻转包 `-x` 与原包 `x` 的 `rho` 恰为 1，与恒等包并列；D1-1 §3.2「并列取共同包序号最小者」导致翻转包排第一时被选为锚包，其余 3 个正常包被 `inter_packet_phase_offset` 拒绝，`n_accepted=1`，输出只剩翻转包。输出本身是真实包、未伪造，但**接受集与折叠结果依赖包顺序**，且丢弃多数一致包。

**F2（低，输入不可达但输出契约要求）非有限值防护不完整。** 非参考通道出现 `NaN/Inf` 时：`gamma` 的 `den>0` 判据把该通道排除出中位数，但折叠 `seg.mean(axis=1)` 仍把它纳入平均，`signals_folded` 出现 `NaN` 而**无报错**；D0 的 `int16` 原始路径不可达，但契约 §2.5/§4.1 要求输出全有限。另：`channel_valid=False` 的通道同样被无条件折入。

## 2. 硬性验收性质（P 项）

### P-F1 锚包与顺序不变性

| 编号 | 性质 | 通过标准 |
|---|---|---|
| P-F1-1 | 1 个极性翻转 + 3 个一致包，翻转包位于任意位置 | 接受集恰为 3 个一致包；翻转包以 `inter_packet_phase_offset` 拒绝；`signals_folded` 与一致段逐点相等（`max|diff| = 0`）；锚包属于一致包 |
| P-F1-2 | 3 个翻转 + 1 个正常（多数在翻转侧） | 接受 3 个多数包（`n_accepted=3`），拒绝 1 个少数包；输出为 `±s` 之一且逐点等于该簇的原始段（不混合、不旋转） |
| P-F1-3 | 2 vs 2 无多数 | 只接受同一簇的 2 包，输出 `±s`；同一输入重复调用结果逐位一致（并列的取舍规则可依赖稳定键，但必须确定） |
| P-F1-4 | 3 个一致 + 1 个翻转 + 1 个 20 ps 延迟包，循环换序 | 5 种顺序下按标签映射的接受集都为 4 个一致包（含延迟包），只拒绝翻转包；输出逐点等于 `(3s + d)/4`（与顺序无关） |
| P-F1-5 | 锚包不得来自被相位门控拒绝的簇 | `meta.anchor_index` 对应的包必须在接受集中 |
| P-F1-6 | **不得引入补偿** | 上述所有接受包的折叠输出必须逐点等于「接受包原始段的等权平均」；延迟 20 ps 的包不得被时移/旋转后再平均（`delta` 只用于门控与日志） |

判据理由：门控的职责是**只拒绝、不修正**（契约 §0/§2.5）。F1 的正确修法是让锚包评分包含相位一致性（例如「以该包为锚时通过全部包间门控的同伴数」或「按 `|phi|` 聚类取最大簇」），而不是对翻转包做 `-1` 乘法或相位旋转。后者会伪造数据并越过 D1 边界。

### P-F2 非有限值输入/输出

| 编号 | 性质 | 通过标准 |
|---|---|---|
| P-F2-1 | **输出全有限** | 对含 `NaN/Inf` 的输入，`signals_folded` 不得含任何非有限值；若整组无法安全折叠，抛 `FoldGateError` 并在消息/日志中说明，不得返回部分污染数组 |
| P-F2-2 | **异常显式** | 非有限值必须被显式登记：包级拒绝原因含 `nonfinite`（大小写不敏感）或通道级 `channel_valid=False` 且该通道输出为 0；二者必居其一，禁止静默通过 |
| P-F2-3 | 坏包隔离（质量项，见 §4） | 一个包坏、另一个包好时，好包应仍被接受并进入折叠；整组拒绝属安全但过保守，记 `FINDING` 而非直接判负 |
| P-F2-4 | 参考通道既有语义保持 | 参考通道非有限仍以 `reference_channel_nonfinite` 拒绝该包；参考通道 `channel_valid=False` 仍以 `reference_channel_invalid` 拒绝 |
| P-F2-5 | `channel_valid=False` 通道不污染输出 | 即使 `channel_valid[5]=False` 且该通道样本为 `NaN`，输出仍全有限；该通道不得以非有限值进入 `signals_folded` |
| P-F2-6 | 诊断可序列化 | 诊断载荷经 `_json_ready` 后 `json.dumps(..., allow_nan=False)` 成功（报告中不得出现裸 `NaN`） |
| P-F2-7 | 输入不可变 | 调用前后 `packets` 逐元素相等（含 `NaN` 位置，`equal_nan=True`） |

## 3. 固定合成例与解析预期

所有合成包为 64 通道相同、`16000 = 4×4000` 点；`s` 为带限实信号（`seed=7`、幅度 12000、仅 bin 300..1700），`flip = -s`（`int16` 取负精确，`min=-12000`、`max=9957`，逐点绝对值之和 `9638861`），`d = round(frac_delay(s, 0.08 样点))`（20 ps 滞后）。

| 量 | 解析/独立值 | 说明 |
|---|---|---|
| `rho(d, s)` | `0.998708955866344` | 由 1401 个带内 bin 的几何和独立算出；> `rho_min=0.99`，应接受 |
| `delta(d, s)` | `20.00052565981888 ps` | 加权线性相位拟合；< `50 ps`，应接受 |
| `phi(d, s)` | `4.681750251186415e-06 rad` | 纯时延；< `0.1 rad` |
| 3 个 `s` 的折叠 | 逐点等于 `s`（`float64`） | 等权平均 3 个相同段 |
| `(3s + d)/4` 前 8 点 | `[-187.0, -625.75, 1023.75, 5829.25, -3419.5, -7489.0, 3970.75, 1761.5]` | P-F1-4 的逐点预期（余下点由套件按同一整数式重算） |
| 3 个 `flip` 的折叠 | 逐点等于 `-s` | P-F1-2 允许 `±s`，按多数簇符号 |

**验收用例**（详见 `checks/A/test_d1_2_independent.py`）：

1. 翻转包在位置 0/1/2/3：接受集、锚包、拒绝原因、折叠值。
2. 3 翻转 + 1 正常；2 vs 2 并列（确定性）。
3. 3 `s` + 翻转 + `d` 的 5 种循环顺序：接受集按标签不变、折叠值 `(3s+d)/4`。
4. 2 包 `[s, d]` 均接受：折叠值 `(s+d)/2`（证明无时移补偿）。
5. `NaN/Inf` 在非参考通道、参考通道、`channel_valid=False` 通道；单坏包与坏+好包；输入不可变；JSON 无裸 NaN。
6. 空场 `data1`：接受集、折叠值、锚包相对统计量、阈值、版本、确定性。

## 4. 观测项（不作为单独阻断条件）

- **F2 策略**：包级拒绝 vs 通道级剔除，二者都可接受；只要求 P-F2-1/2/5。若整组拒绝导致好包被丢弃（P-F2-3），记 `FINDING`，由统筹决定是否要求改进。
- **并列锚包**：2 vs 2 时的稳定取舍规则（最小序号/最小 `sync`）属实现细节，只要求确定性，并建议写入契约。
- **新原因码命名**：只要含 `nonfinite` 语义并在契约 §3.3 登记即可，不强制具体字符串。
- **锚包变化对 `data1` 诊断数字的影响**：若新规则改变 `data1` 锚包，`rho/delta/phi` 相对值会随之变化；P-R-3 按「报告锚包」重算，不要求锚包恒为 1，但要求契约与诊断 JSON 同步更新并说明。

## 5. 对 D1-1 历史套件的处理

`checks/A/test_d1_independent.py` 的 C1a/C1b/C1x 断言的是 D1-1 的**缺陷行为**（锚包=翻转包、只接受 1 包、换序改变接受集）。D1-2 修复后这些断言必然失败，不能作为回归标准。本轮在该文件中加入 `CONTRACT_VERSION` 版本门控：仅在 `D1-1` 上执行 C1 系列；`D1-2` 上打印跳过说明，由 `test_d1_2_independent.py` 的 P-F1-1..6 接管。历史结果 JSON 保留，不改写。
