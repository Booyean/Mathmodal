### 3.1 DAS 与 60 cm 闭环（V1，复跑通过）

独立链路（不调用生产脚本）：按 §8.1 构造 RX1/RX2 的空场与含目标观测 → 用空场比值做相对校准（加权相位投影得 `Δτ₂`、`G₂`、`ψ₂`）→ 单通道残差最小化求 `Δt₀` → 对齐空场模板并用 `S` 匹配求 `t₀,eff` → 在 `[0.55, 0.65] m`、10 µm 网格上分别计算 `P_norm`、`P_env` 与旧未归一化式。

- `P_norm` 的峰值为 Cauchy–Schwarz 等号点：无噪回波 `X ∝ a(d₀)`，`|a^H W X|²/(a^H W a)` 在 `d=d₀` 取全局最大，数值上正落在 `0.600000 m`。
- 旧式在分子乘 `R_i(d)`，真值处一阶导数含正项 `Σ_i R_i'(d₀)/R_i(d₀)`，独立复现 `0.620000 m` 与正斜率。**审阅反例成立，修订后的归一化式确实消除该偏差。**

### 3.2 可识别性（V1，复跑通过）

### 3.6 有效零点符号记账：修正已复核（V3 提出，V4 复测通过）

V3 在 `0f521a4` 上指出 §4.1 的 `H_ref ∝ exp(−j2πf_R τ_hw)` 与 `t0_eff = t0 + τ_hw` 不能并存（锚点差 `2τ_hw`、规范漂移 `2a`）。作者在 `098e17d` 采用 `(+,+)` 修法：

$$H_{i_{\text{ref}}}(f_D) = H_0\, e^{+j 2\pi f_R \tau_{\text{ref}}^{\text{hw}}}, \qquad t_{0,\text{eff}}^{(g)} \triangleq t_0^{(g)} + \tau_{\text{ref}}^{\text{hw}}, \qquad (\tau_{\text{ref}}^{\text{hw}})' = \tau_{\text{ref}}^{\text{hw}} - a.$$

**独立核对点**：

1. 与 §3.2 一致：正物理滞后为 `exp(+j2πf_R τ)`，`H_ref` 的 `+` 号不再把“硬件滞后”写成负相位。
2. 规范不变：在 `(H_i, t_0) → (H_i e^{−j2πf_R a}, t_0 + a)` 下，`H_ref → H_0 e^{+j2πf_R(τ_hw−a)}`，故 `(t_0 + a) + (τ_hw − a) = t_0 + τ_hw`；文本已显式写出该参数映射与 `(t_0,eff)'` 等式。
3. 独立数值（M0-17，`τ_hw = 0.35 ns`、`t_0 = 120.25 Ts`、带内 `f_R = f_s − f_D`）：

| 场景 | 数据锚点 `argmax_t abs(Σ S_eff S* e^{−j2πf_Rt})` | 与声明值之差 |
|---|---|---|---|
| `H_ref = exp(+j2πf_R τ_hw)` | `121.650000 Ts`（`t0 + τ_hw`） | `0.000 ps` |
| `H_ref = exp(−j2πf_R τ_hw)` | `118.850000 Ts`（`t0 − τ_hw`） | 文本声明 `t0 + τ_hw` → **`0.700 ns`（`2τ_hw`）** |

规范不变性同样只在同号时成立：在 `(H_i, t0) → (H_i e^{−j2πf_R a}, t0 + a)`（`a = 0.10 ns`）下，数据相对变化 `1.28e-13`（不变），而文本的 `(−,+)` 组合使 `t0_eff` 漂移 **`2a = +0.200 ns`**；`(+,+)` 与 `(−,−)` 两种同号组合均严格不变（`0.000 ns`）。

4. 检查已从“只认 `(+,+)`”改为“两种同号修法均可、异号必失败”：若将来改用 `(−,−)`（保留负号、`t0_eff = t0 − τ_hw`），M0-17 仍通过，报告会附注“§3.2 正时延约定下 `τ_hw` 应声明为负滞后/提前量”。这避免把某一种正确修法误判为失败。
