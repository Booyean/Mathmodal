## 2. 预登记的可检查性质 P1–P13

| ID | 检查 | 预期（判据） | 不满足的含义 |
|---|---|---|---|
| P1 | 形状 / 类型 / 有限性 | `shape == (64,4000)`、`dtype == float64`、无 NaN/Inf | 接口不合约，下游无法实现 |
| P2 | 折叠口径是**均值**不是和 | S1 `fold == 原段`（maxdiff 0）；data1 `fold_rms_ratio` 中位 `0.9997`（求和口径会 ~4） | 幅值整体放大 4 倍，后续校准/测距全错 |
| P3 | 段索引约定 | 第 `q` 段 = `x[q*4000 : (q+1)*4000]`，`q=0..3`。S2/S3 用已知时移可判别错位 | 段错位会让"一致性"变成伪指标 |
| P4 | 发射通道 27 | 不参与接收平均；若保留该行，必须注明其来源与不参与 63 路统计 | 与 D0 `rx_mask` 契约冲突 |
| P5 | 理想周期保真 | S1：`rho=1`、`dphi=0`、`coh=1`、`fold_maxdiff=0` | 折叠本身有损 |
| P6 | 已知整数时移响应 | S2：`rho=0.951057`、`dphi=-18°`、`coh=0.990781`（k=100，移 2 样本） | 度量定义与相位/时移语义不符 |
| P7 | 线性相位斜坡衰减 | S3：`rho_q1=0.987688`、`rho_q2=0.951057`、`dphi_q3=-27°`、`coh=0.984644` | 同上，斜坡情形未覆盖 |
| P8 | 坏段处理 | S4：全 0 段的 `rho` 无定义 → **必须拒绝并记录**；折叠只用有效段（`fold_maxdiff=0`）；不得补零冒充；全部被拒时显式报错（不返回全 0） | 静默补零会伪造信号 |
| P9 | 包间相位诊断 | S5：30° 公共相位 → `rho=0.866025`、`dphi=+30°`；data1 参考通道 28 的实测漂移见 §3 | "包间一致性"未真正检查 |
| P10 | 拒绝账本闭合 | 接受段数 + 拒绝段数 = 63×4×`P`；每条含 `(packet, channel, segment, metric, value, threshold, reason_code)`；组级拒绝率与 §3.4 的扫描一致（差异 > 2 个百分点需解释） | 无法审计、无法复跑 |
| P11 | 确定性 / 无副作用 | 同一输入连续两次输出逐位相同；不修改输入数组 | 不可复现 |
| P12 | 数值精度 | S6：幅值 30000 的 4 段均值折叠仍为 30000，不回绕（`int16` 直接累加会溢出） | 大信号段被数值截断 |
| P13 | 门限依据与冻结 | 每个阈值给出量纲（度 / ns / 相关系数）、物理或统计来源、在 data1 上的拒绝代价；阈值在看检验组前冻结 | 事后按数据调参 |

补充口径：`rho`、`dphi`、`coh` 的定义见 `d1_prereg_probe.py` 顶部文档字符串。
若 D1 采用**不同但等价**的度量（例如全带相位拟合、循环相关峰移），必须显式声明定义，
并在同一批段上用两条口径互相复算；不能只报一个汇总数。

## 3. 空场 data1 的预登记事实（实现必须能解释或复现）

来源：`python checks/A/d1_prereg_probe.py`，环境 CPython 3.13.x、纯标准库，运行约 1.1 s。
原始输出：`checks/A/d1_prereg_expected.json`。

### 3.1 输入事实

- 8 行文件，各 `1,024,112 B`，各 4 包；共同 `sync = [114,115,116,117]`；扫描问题 0。
- 63 个接收通道（27 号发射通道不参与），共 4×63×3 = **756** 个段对。

### 3.2 段内一致性与相位漂移（k=1000，1.0 GHz）

| 量 | 值 |
|---|---|
| `rho`（段 q 与段 0 的 Pearson） | min **0.943803**（通道 63），p01 0.976930，中位 0.999209，max 0.999976 |
| `abs(dphi)` | 中位 **0.6145°**，p99 8.5534°，max **39.5544°**（= 0.1099 ns） |
| `coh`（4 段复相干增益） | min 0.953805，中位 0.999967 |
| `fold_rms_ratio`（均值折叠 / 段均 RMS） | min 0.981814，中位 **0.999705** |

逐包：

| sync | `rho` min | `abs(dphi)` max | `coh` min | `rho` 中位 |
|---|---|---|---|---|
| 114 | 0.943803 | 39.5544° | 0.953805 | 0.998807 |
| 115 | 0.979883 | 17.0851° | 0.994590 | 0.999512 |
| 116 | 0.975903 | 13.0503° | 0.994208 | 0.999510 |
| 117 | 0.976876 | 27.4501° | 0.984779 | 0.998388 |

最差的 5 个通道（最小 `rho`）：63（0.943803）、62（0.972107）、0（0.980009）、
61（0.984447）、47（0.984787）——集中在阵列边缘，使用这些通道时必须引用本表。

### 3.3 包间一致性（第 `p` 包 vs 第 0 包，段 0）

| 对比 | `rho` | `dphi` | 时延 |
|---|---|---|---|
| 参考通道 28：115 vs 114 | 0.999913 | +0.0252° | −0.00007 ns |
| 参考通道 28：116 vs 114 | 0.999937 | +0.2780° | −0.00077 ns |
| 参考通道 28：117 vs 114 | 0.999487 | −1.6963° | +0.00471 ns |
| 全 63 通道（所有包对） | min 0.967508 / 中位 0.998464 | max 13.1331°（中位 0.8650°） | 0.0365 ns |

结论（仅限 data1）：包内 4 段与包间都高度一致，data1 上"按包相干平均"在数值上可行；
但这**不能外推**到其他组，D1 若默认跨包平均，必须给出包间门限与拒绝记录。

### 3.4 候选门限的拒绝代价（756 个段对）

| 阈值 | 拒绝比例 | 段数 |
|---|---|---|
| `rho < 0.90` | 0.00% | 0 / 756 |
| `rho < 0.95` | 0.13% | 1 |
| `rho < 0.98` | 1.98% | 15 |
| `rho < 0.99` | 6.35% | 48 |
| `rho < 0.995` | 12.83% | 97 |
| `rho < 0.999` | 43.78% | 331 |
| `abs(dphi) > 1°` | 30.56% | 231 |
| `abs(dphi) > 2°` | 9.52% | 72 |
| `abs(dphi) > 5°` | 2.91% | 22 |
| `abs(dphi) > 10°` | 1.06% | 8 |

这张表就是"门限必须有依据"的具体含义：取 `rho ≥ 0.99` 会在 data1 上拒绝 48 段，
取 `abs(dphi) ≤ 1°` 会拒绝 231 段（30.6%）。任何选择都要说明为什么这是"坏段"而不是
正常噪声/边缘通道效应；只报一个"全部通过"的阈值（例如 `rho ≥ 0.9`）则区分力不足，
需要在报告里承认。

## 4. 验收流程（拿到 dsh 首个提交后照此执行）

1. **版本核对**：独立目录检出提交，记录 `HEAD`、父提交、`git diff --stat origin/main...HEAD`、
   改动文件 blob SHA；确认没有改动 D0 读取器、没有引入检验组数据。
2. **只读复跑**：不改被验实现；所有临时输出写到独立目录。
3. **合成例 S1–S6**：用 D1 的实现（不是本探针）重跑等价输入，对照 §3.5；至少覆盖
   理想周期、已知时移、坏段、全拒、幅值边界。
4. **真实单组**：跑空场 data1，取得 `signals_folded`、逐包漂移日志、拒绝日志；与 §3.2–3.4 对照。
5. **账本核对**：拒绝账本闭合（P10）；阈值有依据（P13）；阈值是否在 data1 之前登记。
6. **结论三态**：通过 / 失败 / 依据不足。失败与依据不足都必须写明版本、输入、命令、
   预期、实际、影响范围；数据/代码问题退 dsh，公式/口径问题退建模负责人，题意分歧交统筹。
7. **复测**：dsh 修正后对新提交重跑 1–6，并注明与上一轮的差异。

通过的最低条件：P1–P12 全过；§3 的数字要么被复现（同一度量，容差 `rho≤1e-3`、
`dphi≤0.05°`），要么给出等价定义与逐段对照表；拒绝日志完整可审计。

判为"依据不足"的典型情形：只有汇总没有逐段日志；没有阈值来源；无法复跑；用检验组
标签调过参；把"data1 通过"写成"折叠门控在全部组有效"。

## 5. 待确认项（不阻塞预登记，但实现前应有答案）

1. **相位口径**：单 bin（1 GHz）复相关 vs 全带拟合/循环相关峰移。本文件用前者，
   因为它可手算、可复现；D1 若换口径须声明并给对照。
2. **包间是否允许相干平均**：data1 参考通道漂移 ≤1.7°，但其他组未知；跨包平均必须有门限。
3. **段与发射零点的关系**：M0 明确不假定采集起点对齐；折叠只做段间一致性，不得隐含对齐或补偿。
4. **整包丢弃**：某包全部段被拒时是丢包还是报错，需要登记；不得静默用其他包顶替。
5. **data1 是否可作为调参组**：data1 是空场校准组，可以用作诊断；但门限必须在检验组前冻结。
