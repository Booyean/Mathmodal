## 2. 符号、单位与坐标约定（提议，待 M0 确认）

### 2.1 常量

| 量 | 符号 | 值 | 来源 |
|---|---|---|---|
| 采样率 | `fs` | 4 GHz，`Ts = 0.25 ns` | PDF 第 3 页 |
| 每周期样点 | `Np` | 4000，`Tp = 1 µs` | PDF 第 3 页 |
| 数字扫频 | `fstart, fstop` | 0.3, 1.7 GHz | PDF 第 3 页 |
| 带宽/斜率 | `B, K` | `1.4 GHz`，`K = B/Tp = 1.4e15 Hz/s` | 计算 |

| 光速 | `c0` | 299792458 m/s（本文件约定） | SI |

> 单位约定：距离统一用 **cm** 入表、**m** 参与公式；时延用 **ns**；样点索引 = `tau * fs`。若求解器改用 `c = 3e8 m/s`，42 cm 处约差 `0.069%`（约 0.03 cm），必须在结果中注明，不能与 `c0` 结果混用。`K` 常被误写为 `1.4e12`；按 `Tp = 1 µs` 应为 **`1.4e15 Hz/s`**。

### 2.2 坐标（提议）

以阵列平面为 `y = 0`，`x` 沿阵列水平方向（列方向），`z` 为高度，`y` 为离开阵列指向墙体的深度。发射天线 `T = (0, 0, 54.5 cm)`（组内相对坐标）。第 `r` 行（1–8）、行内第 `k` 副（1–8）接收天线：

- 奇行用奇数列、偶行用偶数列：`col = 2k-1`（奇行）或 `2k`（偶行）；
- `x = 3.5*(col-1) - 24.5` cm（以发射天线为原点）；
- `z = [75.5, 68.5, 61.5, 54.5, 47.5, 40.5, 33.5, 26.5][r-1]` cm。

PDF 第 7 页写“阵列平行于 `yOz` 平面”，但同页给出发射天线在 `xOy` 平面的投影 `(xj, 0)`，两者只有在“`x` 沿阵列、`y` 为深度”时自洽。**该约定必须由 M0/统筹确认**（见 O-03），否则二维/三维成像的坐标符号会整体错位。

## 3. 独立预期（可手算）

### 3.1 参考波形

```
w[n]  = 0.54 - 0.46 cos(2π n/(Np-1))          n = 0..Np-1
φ[n]  = 2π(fstart nTs + 0.5 K (nTs)^2)
s[n]  = 30000 w[n] cos(φ[n])
```

| 检查 | 预期 | 实测（测试输出） |
|---|---|---|
| `w[0] = w[Np-1]` | 0.08 | 0.080000 |
| `max w` | 1.0 | 1.000000 |
| `s[0] = 30000*0.08*cos0` | 2400.0 | 2400.000000 |
| `max|s|` | ≤ 30000 且接近 30000 | 29999.996 |
| `K` | `1.4e15 Hz/s` | 1.400000e+15 |

注意汉明窗分母是 `(Np-1)Ts`，不是 `Np Ts`；`s[0]` 不是 0。

### 3.2 射频镜像

```
fD(t) = fstart + Kt                 （数字，0.3→1.7 GHz，上升）
fR(t) = fs - fD(t)                  （射频，3.7→2.3 GHz，下降）
sR(t) = A w(t) cos(2π fs t - φD(t))
```

- `fR(0) = 3.7 GHz`，`fR(Tp) = 2.3 GHz`。最后一个样点 `n=3999` 处 `fR = 2.30035 GHz`（不是 2.3），因为 `t = 3999Ts < Tp`。
- 采样恒等式：`sR(nTs) = s[n]`，实测 `max|sR-s| = 9.47e-08`。

### 3.3 时延、距离、分辨率

| 量 | 公式 | 数值 |
|---|---|---|
| 双程时延 | `τ = 2d/c0` | 42 cm → 2.8019 ns |
| 样点时延 | `d_s = τ fs` | 42 cm → 11.2078 样点 |
| 单样点双程距离 | `c0/(2fs)` | 3.7474 cm/样点 |
| 距离分辨率 | `c0/(2B)` | 10.7069 cm |
| 一周期无模糊距离 | `c0 Tp/2` | 149.896 m |

42 cm 目标在整数样点上应落在 **+11**（最近整数），不是 `-11`；正时延 = 更晚到达 = 正 lag。用 `d/c0` 代替 `2d/c0` 会把距离系统性地减半。

### 3.4 平面目标的双站几何

发射 `T=(x_t,0,z_t)`、接收 `R=(x_r,0,z_r)`、墙/板前表面在 `y=d` 且平行于阵列时，镜面反射点位于中点，路径为

```
p = sqrt( (2d)^2 + (x_r-x_t)^2 + (z_r-z_t)^2 )
```

而不是 `2d + ...` 的近似。`d = 42 cm`、`Δx = 28 cm`、`Δz = 0` 时 `p = 88.544 cm`，若按单站 `p/2` 报距离会得到 `44.272 cm`，**偏大 +2.272 cm**。同一组内不同接收通道的 `Δx`、`Δz` 不同，必须逐通道用上式补偿；否则几何路径差会被误当成硬件时延差。

### 3.5 周期与记录

- 一个包 16000 样点 = **4 个周期**；PDF 所述 12000 样点 = **3 个周期**，是提取结果，不是 `.dat` 的原始包长。
- 若用数字平移 `s[n-d_s]` 代替真实射频延迟 `sR(nTs-τ)`，两者相差一个载波相位 `2πfsτ`：

```
sR(nTs-τ) = Re{ e^{j2πfsτ} · s_a(nTs-τ) }
```

其中 `s_a` 是 `s` 的解析信号。`d_s = 11.2078` 时，直接平移与真实波形的相对 RMS 差为

```
|1 - e^{j2πd_s}| = 2|sin(π d_s)| = 1.214631
```

实测 `1.214632`。**只有 `d_s` 为整数时该相位项才消失**；因此不能把“数字序列平移”当成物理延迟，必须用解析信号/射频模型或在频域显式补偿 `2πfsτ`。这是本题“射频镜像”最容易被忽略的一处。

## 4. 五项必查

### 4.1 时延符号（DL）

| ID | 检查 | 预期 | 实测 |
|---|---|---|---|
| DL-01 | 物理延迟 vs 朴素数字平移 | 相对 RMS 差 = `2|sin(π d_s)|` = 1.214631 | 1.214632 |
| DL-02 | 解析相关峰位置 | `+11` 样点（42 cm，双程） | `+11` |
| DL-03 | 负时延（超前） | `-11` 样点 | `-11` |
| DL-04 | 实值相关损失 | 实值/解析峰值比 < 0.6，且峰值可能移动 | 0.4014，实值峰移到 `+12` |

**通过标准**：相关定义必须先固定。本文件用

```
r[k] = Σ_n y[n] · conj(s_a[n-k])     （循环相关）
```

`k>0` 表示 `y` 比 `s` 晚到。若改用 `np.correlate(y,s)` 或 FFT 共轭方向不同，lag 轴会整体反号；提交结果时必须写明所用定义。DL-04 说明：不做载波相位补偿的实值相关在 42 cm 处已损失约 60% 峰值，且峰值偏移 1 样点（3.75 cm 双程），不能直接用于测距。

### 4.2 单位（UN）

| ID | 检查 | 预期 | 实测 |
|---|---|---|---|
| UN-01 | 双程时延/样点换算 | 2.8019 ns，11.2078 样点，3.7474 cm/样点 | 一致 |
| UN-02 | 单程/双程 | 用 `d/c` 会减半 | 因子 2.0 |
| UN-03 | 分辨率/无模糊距离 | 10.7069 cm，149.896 m | 一致 |

**通过标准**：距离、时延、样点三套单位在结果表中必须同时给出换算；所有距离除以 2 之前必须确认是双程时延。`cm ↔ m` 的 100 倍错误在 42 cm 处会直接变成 0.42 m 或 4200 cm，不允许只报“误差很小”。

### 4.3 周期移位（PS）

| ID | 检查 | 预期 | 实测 |
|---|---|---|---|
| PS-01 | 记录长度 | 12000 = 3·Np；16000 = 4·Np | 3.0 / 4.0 |
| PS-02 | 三个相关峰 | lag 0/4000/8000 等幅（相对差 < 1e-6） | 1.7e-16 |
| PS-03 | 单周期内唯一 | 限制在 [0,2000] → 0 | 0 |
| PS-04 | 周期内起点 | roll 137 → lag 137，三段仍等于 `s` | 137 / True |
| PS-05 | 未解周期模糊的代价 | 一个 Np = 149.896 m | 一致 |

**必须避免的错误**：对 12000 点记录直接取全局 `argmax`。三个峰等幅，任何噪声或数值误差都可能让结果跳到 `+4000` 或 `+8000`，对应 **149.9 m** 的双程距离错误。正确做法是先限制在一个周期内（或先按已知 `s` 对齐），再估计相对时延。

实测还表明：**采集起点并不在周期边界**。空场 `data1` 的起点 lag 为 `+642`，金属板 `data1-69cm` 为 `+1599`，墙体 `data1-42cm` 为 `-794`（均为模 4000）。因此“16000 = 4 个周期”只说明包长是周期的整数倍，**不能据此认定起点已对齐**；提取 12000 点时必须先定位周期边界。

### 4.4 发射通道（TX）

| ID | 检查 | 预期 | 实测 |
|---|---|---|---|
| TX-06 | 阵列规模/交错 | 64 副，8 行×8 副，奇偶列交错 | 64，行 1 列为 1,3,…,15 |
| TX-07 | 发射位置 | 第 4 行第 8 列：`x=24.5 cm, z=54.5 cm`，A4 第 4 列 | 一致 |
| TX-08 | 接收通道数 | 63，坐标互异 | 63/63 |
| TX-09 | 第 4 行接收偏移 | `[-21,-14,-7,7,14,21,28] cm` | 一致 |
| TX-10 | 含静默 TX 列的均值偏差 | 0.875 vs 1.0（低 12.5%） | 一致 |

**通过标准**：所有逐行/逐通道统计必须基于 **63 路接收**，不能把 A4 第 4 列（发射，实测 RMS 约 25，而其他列约 6000）计入均值、方差、通道数或成像叠加。若按 64 路平均，静默列会把每行均值拉低 12.5%；若按 8 列求和后再除，也会出现同类偏差。通道编号必须同时给出“行号、行内编号、全局列号”三者，避免把行内第 4 副误当成全局第 4 列。

### 4.5 极值（EX）

| ID | 检查 | 预期 | 实测 |
|---|---|---|---|
| EX-01 | int16 边界往返 | `[-32768,-32767,-1,0,1,32767]` 不变 | 一致 |
| EX-02 | `abs(-32768)` | int16 溢出为 `-32768`；int32 为 `32768` | 一致 |
| EX-03 | 全 `-32768` 文件的极值 | int16 路径 `-32768`（错）；int32 路径 `32768` | 一致 |
| EX-04 | 零/哨兵计数 | 0 与 `-32768` 分开显式计数 | 一致 |

**通过标准**：读取后先转 `int32`/`int64` 再做绝对值、求和、平方；极值检测用 `x == -32768`、`x == 32767` 的显式计数，不能用 `max(abs(x))` 代替“是否削顶”。`-32768` 是合法采样值，不是缺失值；`0` 也是合法值（空场样例中单包有 71 个零），不能当缺失处理。

## 6. 与 M0 的对接点

M0 提交后，V0 将按下列顺序核对；其中任一项不闭合，V0 不会给出“通过”：

1. **参考通道与相位基准**：选哪一路作 `i=0`？参考通道的硬件时延是否定义为 0？`ψ_i(f)` 是逐频点还是常数？
2. **时延符号**：`τ_i` 的定义是“到达更晚为正”还是相反？与 `exp(-j2πfτ)` 的符号是否一致？
3. **坐标与路径**：采用第 2.2 节约定还是 PDF 的 `yOz` 写法？`x/y/z` 的正方向、发射投影 `(xj,0)`、阵列平移方向必须一致。
4. **校准参数化**：`H_i(f) = G_i(f) exp(jψ_i(f))` 与整体时延 `exp(-j2πfΔτ_i)` 如何分离？哪些量只相对参考通道可识别？空场直射波与已知距离目标各提供哪一个方程？
5. **距离模型**：单站 `2d`、双站 `sqrt((2d)^2+Δx^2+Δz^2)`、还是含墙内折射/厚度的多层模型？第一问只用前表面，是否明确声明？
6. **亚样点方法**：峰值插值、相位斜率、dechirp 还是匹配滤波后拟合？在 `d_s = 11.2078` 的合成例上预期误差是多少？
7. **周期/对齐**：M0 是否承认 `2πfsτ` 载波相位项？是否承认起点 lag 未知、需先定位？提取 12000 点从哪个样点开始？
8. **评价口径**：测距误差用绝对 cm 还是相对 %？校准残差、直射波抑制比、目标回波保留分别怎么定义？检验组距离是否只进入最终评价？
